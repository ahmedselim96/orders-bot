# Orders Bot — أداة معالجة الطلبات المفقودة (EasyOrders)

بتشتغل لوحدها على GitHub (من غير لابتوب): بتقرا «الطلبات المفقودة»، بتصلّح التليفون والمحافظة والعنوان، بتكتب ملاحظة للكول سنتر، بتحفظ وتحوّلها لطلب، وبتتأكد إن الطلب اتعمل فعلًا ومفيش تكرار.

كل نسخة مربوطة بحساب EasyOrders واحد بس (اللي سجلت دخوله في الخطوة 3). عشان تشغّلها لحساب تاني: اعمل نسخة جديدة من القالب وكرر الخطوات.

## التركيب (مرة واحدة، حوالي 15 دقيقة)

**1) انسخ القالب**
اضغط **Use this template ← Create a new repository**. سيب الريبو **Public** (الـ Private بيخلص دقايق Actions المجانية).

**2) فعّل Actions**
تاب **Actions** ← **I understand my workflows, enable them**.

**3) سجّل دخول EasyOrders وطلّع الجلسة** (على جهازك، مرة واحدة)
```
pip install playwright
playwright install chromium
python save_session.py
```
هيفتح متصفح: سجّل دخول بنفسك (أي OTP/CAPTCHA بإيدك)، افتح صفحة «الطلبات المفقودة»، وارجع للترمنال واضغط Enter. هيطلع ملف `easyorders_state.json`.

**4) حط الجلسة كـ Secret**
**Settings ← Secrets and variables ← Actions ← New repository secret**
- Name: `EASYORDERS_STATE`
- Value: كل محتوى `easyorders_state.json`

الملف ده زي تسجيل الدخول بالظبط: متبعتوش لحد ومتحطوش في الريبو.

**5) ظبط الشحن في EasyOrders**
اعمل **سعر الشحن الافتراضي = 0** في إعدادات المتجر. الأداة بتحط الشحن جوه سعر القطعة لأن الطلب المحوّل من المفقودة بيتحط عليه شحن ثابت من الافتراضي. لو سيبته مش صفر، حط نفس الرقم في الداشبورد (إعدادات ← platform_flat).

**6) فعّل الداشبورد**
**Settings ← Pages ← Source: Deploy from a branch ← main ← /docs**. اللينك: `https://<اسمك>.github.io/<اسم الريبو>/`

**7) اعمل توكن للداشبورد**
**GitHub ← Settings ← Developer settings ← Fine-grained tokens ← Generate**
- Repository access: الريبو ده بس
- Permissions (كلها Read and write): **Actions, Contents, Variables**
الصقه في الداشبورد أول مرة. بيتحفظ في متصفحك بس.

**8) أول تشغيل**
افتح الداشبورد ← **«شغّل دورة دلوقتي»** وهو على **تجربة** (من غير تحويل فعلي). راجع تاب الطلبات. لما تطمن اضغط **تشغيل**.

## أوضاع التشغيل
- **تجربة (dry)**: بتقرا وتحلل وتكتب في اللوج، من غير حفظ أو تحويل. ده الوضع الافتراضي لأي نسخة جديدة.
- **تشغيل (live)**: بتحفظ وتحوّل فعلًا.
- **إيقاف**: الدورات بتتخطى.

## الإعدادات (من الداشبورد، أو `config.json` مباشرة)
جدول الشحن لكل محافظة، المحافظة الافتراضية للمجهول، شحن المنصة الثابت، وحد التحويل في الدورة. القالب جاهز لمصر (30 محافظة). لدولة تانية غيّر الجدول والمحافظة الافتراضية من الداشبورد.

## ملاحظات مهمة
- GitHub بيشغّل الجدولة تقريبًا كل 15–20 دقيقة مش 5.
- اللوج والـ status عامين لأن الريبو Public: فيهم أرقام تليفون مقنّعة وإجماليات بس، مفيش أسماء ولا عناوين.
- لو الجلسة انتهت الأداة بتقف وبتقول كده. كرر الخطوتين 3 و4.
- الأداة بتفضل تعدّل في حسابك الحقيقي: جرّب دايمًا على تجربة الأول.
